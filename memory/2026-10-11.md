### 13:00 ~ 13:15 — 老板决策: 走架构 A (OD 独立 thread)
老板说"为了保证检测的效果是不可能隔帧检测的, 基于该方向, 结合当前代码重点分析看下可行性方向"。

我分析 v31 main loop 单线程结构 + OD 拆 thread 几种架构:
- 架构 A: 主不等 OD, OD 独立 worker (唯一能涨 fps 的方案)
- 架构 B: 主等 OD 同步 (无 fps 提升)
- 架构 C: awnn_run_dual_npu (libod_helper.so 已 export, 但单 NPU 核不能 overlap 推理)

**架构 A**:
```
main (capture + push):              worker_thread (OD):
===================                ===========================
while: while:
  DQBUF                               wait q_frame
  cvtColor → bgr                       pre_process
  push q_frame (drop oldest)            awnn_set_input
  pop q_result last (timeout 0)         awnn_run (35ms ★)
  draw last_det on bgr                  decode_all + nms
  push appsrc                           push q_result
  QBUF
```

预期: fps 19.8 → 30 (camera-bound), det 25Hz, det 延迟 33ms。
